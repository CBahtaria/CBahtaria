Algorithms / Computability
2026
Levin-Optimal
Python 3.11+ stdlib only
Speed-optimised Levin Universal Search over BrainFuck programs with a pluggable success predicate. Asymptotically optimal: O(2|p*| · t*) total work.
  • Incremental execution — delta steps in phase i = 2^(i−|p|−1). Proved equivalent to restart-per-phase with zero wasted work.
  • Dead-set pruning — halted programs removed from active dict permanently; never revisited across phases.
  • O(1) bracket precomputation — jump table built once at machine construction; unbalanced brackets rejected before tape allocation.
  • Kolmogorov complexity CLI — find, run, kolmogorov subcommands; estimates BF bit-length vs raw with compression ratio.
Algorithm
for i := 1, 2, … do
  for each program p with |p| ≤ i do
    run p for at most 2^(i − |p|) total steps
  end for
end for

Optimality bound: O(2^|p*| · t*) — matches any reference machine up to constant 2^|p*|.
