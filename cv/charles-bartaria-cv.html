Algorithms / Computability
2026
Levin-Optimal
Python 3.11+ stdlib only
Speed-optimised implementation of Levin's Universal Search over BrainFuck programs with a pluggable success predicate. Asymptotically optimal: finds any computable function in O(2|p*| · t*) total work.
  • Incremental execution — programs never restart; delta steps in phase i = 2^(i−|p|−1). Proved correct via BF determinism: incremental ≡ restart-per-phase with zero wasted work.
  • Dead-set pruning — halted programs permanently removed from the active dict; never revisited across phases.
  • O(1) bracket precomputation — jump table built once at machine construction; programs with unbalanced brackets rejected before tape allocation.
  • Kolmogorov complexity CLI — find, run, kolmogorov subcommands. Estimates BF bit-length vs raw bit-length with compression ratio.
Algorithm (pseudocode)
for i := 1, 2, … do
  for each program p with |p| ≤ i do
    run p for at most 2^(i − |p|) total steps
  end for
end for

Optimality: O(2^|p*| · t*) — matches any reference machine up to the constant 2^|p*|.
